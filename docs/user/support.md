# Talent-X — Aide & support

> Version 1.0 — juillet 2026. Canal de support pour le lancement (TLX-78 / jalon
> « Lancement & Qualité »).

## Contacter le support

- **E-mail (canal principal)** : `support@talent-x.app`
  ⚠️ *Boîte à provisionner avant le lancement (action ops — voir « Mise en place » ci-dessous).*
- **Délai de réponse visé** : 48 h ouvrées au lancement.
- À joindre pour aller vite : ton **e-mail de compte**, ton **rôle** (coach/athlète), le
  **modèle de téléphone**, et une **capture d'écran** du problème.

## Questions fréquentes

**Je n'arrive pas à me connecter.**
Vérifie l'e-mail/mot de passe ; « Mot de passe oublié » envoie un lien de réinitialisation
(valable une heure). Si l'e-mail n'arrive pas, vérifie les indésirables.

**Le code d'invitation est refusé.**
Le code a pu être **révoqué/régénéré** par le coach — redemande-lui le code actuel. Le code
fait 8 caractères, sans les chiffres 0 et 1 (évite la confusion avec O et I).

**Mon coach ne voit pas mes performances.**
Vérifie **Profil → Confidentialité & données → Accès de mon coach** : le consentement doit
être actif (par coach si tu en as plusieurs).

**J'ai saisi une perf sans réseau, où est-elle ?**
Elle est **en file locale** et repart automatiquement au retour du réseau (bannière « en
attente de synchronisation »). Ne désinstalle pas l'app entre-temps.

**Je veux récupérer/supprimer mes données.**
**Profil → Confidentialité & données** : export (archive à télécharger) et suppression de
compte (définitive sous 30 jours). Pour toute demande RGPD : `support@talent-x.app`.

## Confidentialité

- Données hébergées dans l'**Union européenne** (OVHcloud).
- Les données de performance sont traitées **avec ton consentement explicite**, révocable à
  tout moment ; l'accès coach est **consenti coach par coach**.
- Notifications push : contenu **minimal** (aucune donnée sensible dans le texte des push).
- Détail du traitement : politique de confidentialité (notice in-app) et, en interne,
  `docs/Talent-X_03_Securite_RGPD_v2.md` / `docs/Talent-X_07_DPIA_AIPD.md`.
